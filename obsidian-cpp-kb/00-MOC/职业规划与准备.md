# 职业规划与准备

> **定位锚**：系统后端为地基、AI 数据基础设施为进攻方向——用 C++ 数据面功底 + SangBridge 管控面叙事，2027 下半年双轨上场。
> 本笔记是职业规划总控；八股执行入口在 [[面试知识地图]]，项目素材在 [[项目知识地图]]。

## 一、局面快照（2026-09）

| 事实 | 判断 |
|---|---|
| 2025-07 入职深信服 EDS 存储线 | 首份工作需满 2 年稳定线 → 正赛窗口 = 2027 H2 |
| 湖南工业大学本科 | 第一学历初筛有摩擦 → 主力战场选学历宽容路线（华为系/智驾/AI 存储/AI 平台公司），大厂盲投只当中奖票、走内推 |
| C++ 数据面 + Python 管控面双线 | 叙事不是"C++ 中断"，是"两层都趟过的人" |
| SangBridge 状态仍为"学习中" | 它是王牌：上场前要演进到"能答所有为什么 + 有演进故事" |
| 05-Algorithm 为空 | 社招最大洞 → 低火模式立刻开始 |

## 二、每周节奏（总预算 ≤6h；忙周保底只保算法 2h，其他全停）

- [ ] 算法每周 3–5 题，全部 C++ 手写（~2h）——**最高优先，永不降档**
- [ ] 八股保鲜：每周口头复述 1–2 篇笔记，讲不顺的降级回"学习中"（~1h）
- [ ] SangBridge 演进项：分布式限流 或 audit 启用+观测，二选一落地（大部分在工作时间内）
- [ ] AI infra 实验：vLLM/SGLang 部署压测、3FS 精读（~1h + 周末）

## 三、AI coding 含金量纪律（日常工作中执行，不占额外时间）

> [!important] 三条规则
> 1. **三坑提问**：任何 AI 生成的代码，merge 前必须能答"最坏的三个坑、怎么验证、炸了影响面"。答不出，让 AI 写对抗测试打到能答为止。
> 2. **硬骨头不外包**：契约定义、鉴权/密钥链路、跨节点问题、故障演练——决策与验证类工作 AI 不做，这就是含金量所在。
> 3. **决策留痕**：每个取舍记"为什么选/代价是什么/下一步演进"，回写进项目笔记，攒成月度面试故事。

自检标准：**含金量 = 合上笔记后，能回答系统里多少个"为什么"。** 面试题驱动沉淀就是兑换机制，继续转。

## 四、阶段计划

### Phase 0：2026.09–12 蹲点攒牌

- [ ] 12 月底前：SangBridge 用 AI-infra 叙事连讲 30 分钟不被问穿
- [ ] 投 3–5 个"模考"岗（华为云存储 AI Infra、蔚来 AI Infra 平台这类），只为验证初筛关键词 + 收集真实追问，复盘写回本笔记
- [ ] 产出：vLLM 压测小复盘一篇
- [ ] 产出：3FS 精读 + 一段"如果 EDS 接 AI 训练场景我会怎么改"的话术
- [ ] 年底检查点：上述四项全勾 → 进 Phase 1；缺两项以上 → 压缩 Phase 1 范围

### Phase 1：2027 H1 证据链成形

- [ ] 公开发 2–3 篇：SangBridge 架构与取舍 / vLLM 压测 / 存储人读 3FS
- [ ] 开源 1–2 个 PR（vLLM、3FS 相关：文档、测试、小 bug 起步）
- [ ] 加 2–3 个 infra 方向猎头；激活校友/前同事内推网
- [ ] 春招第二次模考，验证关键词命中情况
- [ ] **关键决策点：评估深信服内部转 AI 产品线**（公司正在向 AI 转：内核 IO、AI 运维、AI 云）。转成功 → 简历主线直接升级为"AI 数据基础设施 2 年"，外部叙事翻倍

### Phase 2：2027 H2 正赛

- [ ] 满 2 年后启动投递
- [ ] 双轨投递：**主投·系统后端**（存储/数据库/中间件/云 infra 团队，深信服 2 年直接对口，命中率最高）；**冲投·AI infra**（华为系 AI 存储、智驾 infra、AI 存储新贵、推理服务商、大厂平台组——同一份简历加 AI 叙事，优先内推+急招窗口）；**保底·通用业务后端**（仅双轨全部失灵才启用，它是用来抬价的不是用来去的）
- [ ] Go 预案：若主投 JD 普遍要求 Go，面试季用两周从 C++ 平移补齐——语言皮不是方向赌注，不提前学
- [ ] 同一轮面试季两轨都投：复盘记录各自的初筛通过率与被追问深度，用真实数据决定下一轮权重
- [ ] 面试前 1 个月冲刺：算法拉回每日一题 + 按 [[面试知识地图]] 第一优先级做追问模拟
- [ ] Offer 判据（按权重）：方向纯度 > 团队与 leader > 涨幅 > 名气。为名气接边缘存储运维岗是最差选项

### Phase 3：2028–2029 护城河

- [ ] 新平台内选 AI 存储 / 推理 infra 纵深，做到"公司内这条链路数得着"
- [ ] 接 1–2 个跨团队技术牵头，往骨干走
- [ ] 2029 再评估大厂核心组——第一学历权重已随平台升级稀释两轮

## 五、决策规则

> [!warning] 五条原则（纠结时回来看）
> 1. 一切动作过同一个滤网：**厚不厚"AI × 系统"这条简历**。
> 2. 不为热度接过渡岗：纯 agent 应用层封装、鸿蒙适配、游戏开放世界——一律降级为素养/爱好。
> 3. 允许提前跳的只有两个触发器：稀缺 offer（接受 1 年经验的 AI infra 核心外围岗）或内部着火（裁员/边缘化/健康）。
> 4. 非全硕士破不了第一学历初筛，不为此花时间；资源全投证据链。
> 5. 岗位越通用，第一学历权重越高：平转"通用业务后端"的所谓高概率是伪命题——筛选器从"拼项目"换回"拼学历"。系统后端 × AI infra 双轨，才是概率与护城河的交集。
> 6. 健康与现金流是约束，不是变量。

## 六、年检（每年 12 月）

- [ ] 工龄数：下一档投递门槛到了吗
- [ ] AI 浓度：今年工时的 AI 相关性升了还是降了
- [ ] 公开证据：文章 / PR / 分享各新增几件
- [ ] 市场温度：模考初筛通过率与被追问深度 vs 去年

任何一项停滞半年 → 修本笔记并收缩范围。
