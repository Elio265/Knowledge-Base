# Python 知识地图

> Python 与后端框架章节，直接对应当前管控组业务（FastAPI 网关）。当前未系统学过 Python，所以本节是「学习路线 + 面试目标」：先补基础，再进并发/框架，最后全部映射回项目。

## 学习阶段

1. **基础**：[[Python语言基础]] —— 语法、函数、类、装饰器、生成器、常用标准库；目标是高频考点能写对、能讲清。
2. **并发**：[[Python并发与asyncio]] —— GIL、线程/进程/协程选型、事件循环；对照 Kerberos 的 eventlet Taskflow。
3. **框架**：[[FastAPI与ASGI后端框架]] —— 依赖注入、中间件、生命周期、统一错误处理；对照 SangBridge 网关。
4. **安全**：[[鉴权与Token方案]] —— Session/JWT、网关身份转发、SigV4；对照 SangBridge 与 Kerberos。
5. **接口**：[[后端接口设计与分页]] —— 游标分页、错误模型、限流；对照 SangBridge 分页治理。

## 学习方式

- 每个阶段先自测/做题，再回来更新对应笔记的 status：学完一项改一项。
- 以项目为锚点：能讲原理，也能讲项目里的落地与边界。
- 未核验为个人成果的平台能力（如 SigV4/S3 Express、WAF、审计）只作原理储备，不写入简历表述。
- 复习入口：[[Python面试串讲总览]] —— 一页纸速记 + 记忆钩子 + 回忆检查，适合复习前快速过一遍。
