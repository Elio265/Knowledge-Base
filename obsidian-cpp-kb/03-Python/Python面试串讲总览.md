# Python 面试串讲总览（2026-08-05）

> 基础阶段 + 并发第一阶段的浓缩串讲。复习方式：先过这一页，再回各主题笔记，最后按底部「回忆检查」自测。

## 高频考点速记

| 考点                      | 一句话                                                                                                                  |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 可变默认参数                  | `def f(x, lst=[])` 共享同一列表；改 `lst=None` 再初始化                                                                          |
| `is` vs `==`            | `is` 比身份（同一对象），`==` 比值；整数缓存 -5~256，`"hello"` 编译期驻留；值比较一律 `==`                                                        |
| 浅拷贝 vs 深拷贝              | 浅拷贝外层独立、内层共享；深拷贝递归全复制；`a[:]` 是浅拷贝                                                                                    |
| 装饰器                     | `@timer` == `work = timer(work)`；收函数、包 wrapper、`return wrapper`；`@wraps` 保留元信息；叠加定义自下而上、调用自上而下                       |
| 生成器                     | 调用不执行，`next` 跑到 `yield` 暂停；惰性、省内存、只能迭代一次                                                                             |
| `with` / 上下文            | `__enter__` 进入、`__exit__` 离开（异常也执行）；`@contextmanager` 用 `yield` 分界，`try: yield finally:` 保证收尾；`__exit__` 返回 True 吞异常 |
| `finally`               | 无论 return/异常必执行；`os._exit()`/进程被杀才跳过；只收尾不吞异常                                                                         |
| 类属性 vs 实例属性             | 类体里的可变对象所有实例共享；`self.x = []` 才是实例私有                                                                                  |
| 三种方法                    | 第一参数 `self`/`cls`/无 = 实例/类/静态方法；类方法里访问类属性写 `cls.count`                                                               |
| `__new__` vs `__init__` | `__new__` 造对象，`__init__` 填属性；`__new__` 用于单例/不可变类型子类/对象池                                                              |
| 推导式与解包                  | 推导式有独立作用域不污染外层；`a, b, *rest = [...]` 星号收集剩余                                                                          |
| 工程基础                    | `if __name__ == "__main__"` 只在直接运行时执行；venv 隔离依赖；requirements 锁版本；生产用 logging 不用 print；json 用 dumps/loads             |

## 并发核心（第二阶段开篇）

- **GIL**：CPython 全局解释器锁，同一时刻只有一个线程执行字节码；存在是为了引用计数等内部状态线程安全；CPU 密集多线程不加速。
- **选型**：CPU 密集 → 多进程；I/O 密集 → 多线程；连接数极大 → asyncio。
- **await = 让出控制权**：挂起当前协程，事件循环去跑别的协程，等 I/O 就绪再回来。
- **gather = 召集**：`asyncio.gather(task_a(), task_b())` 把多个协程同时排队并发跑；`A1 -> A1 -> A2 -> A2` 证明两个任务在等待期间并发推进。
- **asyncio.run()**：创建事件循环、运行协程、结束后关闭。

## 三个记忆钩子（最容易忘的）

1. 装饰器：**收一个函数进来，包一层，还一个函数出去**（`def timer(func)` → `def wrapper(...)` → `return wrapper`）。
2. 生成器：**调用不执行，next 到 yield 停**；再 next 从暂停处继续。
3. `gather`：**召集**——把多个协程召集到一起并发跑。
